# Font credits

- **Cinzel Decorative** by Natanael Gama, under the SIL Open Font License 1.1 (`CinzelDecorative-OFL.txt`). Upstream: https://github.com/NDISCOVER/Cinzel
- **Crimson Pro** by Jacques Le Bailly, under the SIL Open Font License 1.1 (`CrimsonPro-OFL.txt`). Upstream: https://github.com/Fonthausen/CrimsonPro
- **Vigil Pixel** is an original 5 × 7 pixel font made for CRT Crusaders, free to use, embed and modify in the game and its shipped builds. Its glyph grid lives in `tools/make_vigil_pixel.py` (needs `pip install fonttools brotli`). The design grid is 10 px per em, so 10, 20 and 30 px render on whole pixels.
