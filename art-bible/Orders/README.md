# Orders

This directory holds the approved material for the seven Orders of CRT Crusaders. Each Order’s folder opens with its lore and links to its Sister index and approved visual references.

- [The Scarlet Succession](scarlet-succession/)
- [The Vesperglass Testament](vesperglass-testament/)
- [Synod of the Veiled Sun](see-of-the-black-noon/)
- [The Marching Throne](sovereign-breach/)
- [The Wardens of the Inward Gate](wardens-of-the-inward-gate/)
- [The Red Office](red-office/)
- [The Dreadful Salutation](dreadful-salutation/)

Each Order holds a homeland and may operate in other territories. Establish its homeland in unpopulated environment art before drawing on it for Sister designs. Territory studies enter the reference collection when Aaron approves them.

Record individual Sisters under `art-bible/Sisters/` as they are developed. Use each Order’s index to link to those folders. Shared roster decisions, roles, and classes are in the [creative decisions](../CREATIVE_DECISIONS.md).
